# AI Voice-Scam & Deepfake Call Detector — Phase 

Codec-robust detection of synthetic speech under live telephony conditions.

**Base paper:** García Martínez-Echevarría, Palacios, López & Gupta,
*"The Generalization Gap: Do Audio Deepfake Detectors Actually Protect Against
Modern Vishing?"*, Electronics (MDPI) 15(13):2846, 2026.

**Limitation addressed (the paper's own words, Section 6):**
> "All experiments were run on clean benchmark audio, and the models were not
> tested under conditions that characterize real vishing calls (telephone
> bandwidth and codec compression, background noise, reverberation …)"

---

## Headline results

Model: ResNet embedding + OC-Softmax, 323,888 parameters, CPU-only.

| Condition | EER | AUC |
|---|---|---|
| Clean audio (lab) | 0.00% | 1.000 |
| Real telephony codecs | **42.89%** | **0.596** |
| Telephony + codec augmentation | **16.67%** | **0.906** |

Codec augmentation recovers **26.2 percentage points** of EER — a **61% relative
improvement**. The clean → codec collapse (AUC 1.000 → 0.596) closely mirrors the
base paper's reported collapse (0.92–0.99 → 0.50–0.57) against modern TTS.

Honest negative result: the same augmentation applied to the classical LFCC-GMM
baseline made it *worse* (36.22% → 41.44% EER). A 16-component diagonal GMM
lacks the capacity to model the more heterogeneous augmented distribution, so
the gain is specific to the neural model.

Streaming inference: **23.5 ms per 2.5 s window**, real-time factor **0.047**
(~21× faster than real time) on CPU.

## Experimental design

Three conditions, chosen so the argument is one table:

- **E1** train clean → test clean — in-domain baseline
- **E2** train clean → test codec-degraded — *the gap the base paper admits to*
- **E3** train augmented → test codec-degraded — *our proposed mitigation*

E2 − E1 quantifies the deployment gap. E3 − E2 quantifies the contribution.

Channels evaluated: G.711 μ-law (PSTN), G.726 at 16k and 32k (DECT),
Opus at 12k and 24k (VoIP), MP3 32k (stored calls).

---

## Important limitation of Phase 1

The corpus is **synthetic**, generated by a source-filter vocal-tract model.
Bona fide utterances use Liljencrants-Fant-style glottal excitation with jitter
and shimmer; spoofed utterances add the documented artefacts of vocoded speech
(cepstral over-smoothing, Griffin-Lim phase reconstruction, band-limiting,
reduced micro-prosody). It exists because this build machine has no dataset
access.

It is calibrated so the task is non-trivial (GMM baseline ≈ 9–11% EER on clean
audio, comparable to published figures) but it is **not a substitute for real
speech**, and the absolute numbers should not be compared against published
ASVspoof results. The *trend* across the three conditions is the finding.

Phase 2 replaces it with ASVspoof 2019 LA by pointing the loader at the real
corpus — no other code changes required.

## Phase 2 onward

1. Port the identical protocol to ASVspoof 2019 LA (real speech).
2. Replace LFCC with a frozen wav2vec2 / WavLM front end — the base paper lists
   "benchmarking against recent large pretrained audio models" as future work.
3. Cross-corpus evaluation against modern TTS (SONAR, or a self-built set from
   open TTS models over public speech, drawn from the same source corpus to
   avoid a domain confound).
4. Add the scam-intent branch: ASR → transcript classifier, fused with the
   audio-authenticity score.
